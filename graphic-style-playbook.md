# LinkedIn Graphic Style Playbook

A reusable set of visual structures for post graphics — not color variants of
one layout, but genuinely different ways to show the same content. Pull this
up at the start of any new post and pick 2-3 that fit what the post is
actually saying.

Live comparison of all six (may need republishing if you change any):
https://claude.ai/code/artifact/0c4506ae-9857-4227-b639-42064a0d9987

## The six structures

### A — Annotated Breakdown
Real content (a message, a stat, a quote) with labeled call-outs beside or
below each part. Best for: teaching a framework, proving a claim line by
line. This is what most "here's my exact process" posts default to — use it
when the *labels themselves* are the value (Hook / Proof / Ask, Problem /
Insight / Fix, etc).

### B — Document / Note
Looks like an actual annotated note or memo rather than a "designed" card —
serif body text, quiet margin labels, minimal color. Best for: authenticity
over polish; posts where looking hand-made builds more trust than looking
produced.

### C — Chat Bubble / Screenshot
The real content inside a single message bubble or realistic UI frame, with
labels as a legend underneath rather than inline. Best for: "here's literally
what I sent/saw" posts — highest immediate recognizability, fewest design
elements.

### D — Editorial Pull-Quote
One line blown up huge (the hook, the punchiest stat), everything else
reduced to a couple of quiet lines underneath. Best for: fast-scroll impact
when the post's whole point rides on one sentence.

### E — Big-Stat Poster
A single number or short phrase fills almost the entire frame; no
supporting structure at all — the post caption carries the explanation, not
the image. Best for: pure scroll-stop, results-first posts, when the image's
only job is to make someone stop and read the caption.

### F — Carousel (multi-slide)
Not a single image — the framework becomes 3-5 swipeable slides, one idea
per slide. A structurally different post format, not just a graphic style.
Best for: multi-part frameworks, and posts optimizing for LinkedIn's
swipe/dwell-time engagement rather than a single glance.

### G — Signature Voice Bubble
A punchy, opinionated first-person line (a "hot take," not a framework
explanation) inside a bold speech bubble, paired with a small recurring
mark — an initial, a shape, a consistent color — that shows up the same way
on every post. Best for: building personal recognition over time. The value
isn't the individual post, it's repetition — if the mark and voice stay
consistent, people start recognizing "this is her post" before reading a
word. Needs the least explaining and the most personality; works best when
the line is genuinely opinionated, not a restated fact.

## How to use this next time

1. Read the post's actual content and ask: does it live or die on one line
   (→ D or E), on proof of real work (→ A, B, or C), or does it have enough
   distinct steps to justify a swipe (→ F)?
2. Sketch 2-3 candidates from different structures — never two color
   variants of the same one.
3. Palette and type pairing still need to be chosen deliberately per post,
   not reused on autopilot — but the *structure* choice above should
   usually come first.

## Palette notes (avoid repeating the same look every time)

Used so far, kept genuinely distinct from each other:
- Near-black + warm coral/orange
- Warm off-white + serif + ink blue
- Warm gray + white + teal
- Deep forest green + mustard gold
- Slate blue-gray + copper
- Warm putty/parchment + rust

Avoid defaulting to: warm cream + terracotta, near-black + acid green, or
purple-to-blue gradients — these read as generic "AI-generated design" at
this point and should only be used if deliberately chosen for a reason.
